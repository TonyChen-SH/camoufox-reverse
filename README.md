# Camoufox Reverse

Native API tracing for diagnosing browser compatibility and fingerprint inconsistencies.

The experimental implementation is developed on [`codex/native-trace-pilot`](https://github.com/TonyChen-SH/camoufox-reverse/tree/codex/native-trace-pilot) and reviewed through pull requests. It targets a pinned Camoufox/Firefox source revision; no compiled browser binary is currently provided.

Trace collection and read-only analysis: [camoufox-reverse-mcp](https://github.com/TonyChen-SH/camoufox-reverse-mcp).
